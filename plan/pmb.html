Plan: PMB — Penerimaan Mahasiswa Baru

Sistem pendaftaran mahasiswa baru dengan dua jalur: Baru dan Pindahan/Mutasi

⚠️ Asumsi yang perlu dikonfirmasi:
  • NAMA BERDOMISILI → diasumsikan sebagai alamat lengkap tempat tinggal
  • NAMA REFERENSI (SESUAI KTP) → diasumsikan nama orang yang mereferensikan si pendaftar ke STIE
  • PRINTOUT BIODATA DI PP/KTI → field upload dokumen, diasumsikan biodata dari sistem kampus sebelumnya. Tolong konfirmasi kepanjangan PP/KTI.
  • KARTU TANDA ANGGOTA di pindahan → diasumsikan KTM (Kartu Tanda Mahasiswi) dari kampus sebelumnya
  • Admin dashboard → diasumsikan ada fitur ubah status (Menunggu → Diproses → Diterima/Ditolak) + catatan admin

2. Halaman Form Publik

Landing — /pmb atau /form-pmb

Halaman pilihan jalur pendaftaran

  • Dua tombol besar: BARU dan PINDAHAN
  • Brief info syarat masing-masing jalur
  • Link ke form masing-masing

Form Baru — /pmb/baru

Form multi-section dengan scroll

  • Section 1: Data Calon Mahasiswi
  • Section 2: Data Akademik
  • Section 3: Data Orang Tua / Wali
  • Section 4: Upload Berkas
  • Validasi wajib sebelum submit
  • Halaman sukses dengan nomor pendaftaran

Form Pindahan — /pmb/pindahan

Form multi-section dengan scroll

  • Section 1: Data Mahasiswi Pindahan
  • Section 2: Data Akademik Kampus Lama
  • Section 3: Upload Berkas (semua opsional)
  • Validasi wajib sebelum submit
  • Halaman sukses dengan nomor pendaftaran

Halaman Sukses — /pmb/sukses

Konfirmasi setelah submit

  • Tampilkan nomor pendaftaran (ID)
  • Instruksi langkah selanjutnya
  • Kontak admin jika ada pertanyaan

3. Admin Dashboard

List Pendaftar — /admin/pmb

  • Tabel semua pendaftar
  • Kolom: Tanggal, Nama, Tipe, Program Studi, Status
  • Filter: tipe (baru/pindahan), status, tanggal
  • Search by nama / NIK
  • Klik baris → buka detail
  • Badge status berwarna

Detail Pendaftar — /admin/pmb/[id]

  • Tampilkan semua data yang diisi
  • Preview / download berkas yang diupload
  • Ubah status: Menunggu → Diproses → Diterima / Ditolak
  • Input catatan admin
  • Tombol kembali ke list
